# Be-Vui-Hoc-Toan-123
Vui học Toán cùng cô Ngọc là website học Toán tương tác dành cho trẻ mầm non. Website cung cấp các trò chơi sinh động về số đếm, cộng, trừ, hình học với hai mức độ: Dễ (phạm vi 10) và Nâng cao (10–20), giúp trẻ phát triển tư duy, hứng thú học tập và hỗ trợ giáo viên theo dõi kết quả.


## Bản đã chỉnh âm thanh (bản thử nghiệm)

- Giữ các trò chơi có trong mã nguồn tải về.
- Bỏ nút đọc lời hướng dẫn và bỏ giọng đọc tổng hợp.
- Thêm âm thanh hiệu ứng ngắn khi thao tác, âm báo riêng khi trả lời đúng/sai.
- Âm thanh được tạo bằng Web Audio API trong trình duyệt; không cần tệp âm thanh ngoài.

Lưu ý: Đây là bản ZIP chỉnh sửa để kiểm tra trước khi đưa lên GitHub/Vercel. Hãy giữ nguyên bản gốc để có thể quay lại nếu cần.
